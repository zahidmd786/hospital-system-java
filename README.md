# hospital-system-java
Hospital Management System built in Java (Swing) with MySQL database. Includes login authentication, patient registration, staff management, and billing features.

The Hospital Management System is a Java-based desktop application designed to simplify hospital operations such as patient management, reception handling, and secure staff login.
This project demonstrates Java Swing for UI, MySQL for database, and JDBC for connectivity.

Features
Secure Login System (Admin & Reception)
Reception Dashboard – manage patient records
Patient Information Management (CRUD operations)
Database Integration with MySQL
Modern UI with custom background and buttons
